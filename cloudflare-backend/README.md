## ⚡ كيف يعمل البوت لإدارة المنتجات؟

### 1. إضافة منتج جديد بالصورة والمعلومات:
أرسل **صورة الحقيبة** إلى البوت أو في المجموعة `-5586000352`، واكتب في نص الشرح (Caption) المرافق للصورة:
```text
اسم: حقيبة لابتوب جلدية فاخرة
سعر: 9500
لون: بني
سلسلة: classic
وصف: جلد صناعي مقاوم للماء سعة 15.6 بوصة ومناسبة للاجتماعات
```
> **ماذا يحدث تلقائياً؟**
> 1. يقوم الـ Worker بتحميل الصورة مباشرة من تيليجرام وتخزينها في Cloudflare KV.
> 2. يتم إنشاء رمز مرجعي فريد (SKU) ومعرف للمنتج.
> 3. يُحفظ المنتج فوراً ويظهر على الموقع في واجهة الزبائن.
> 4. يرسل البوت رسالة تأكيد تحتوي على معاينة المنتج وزر للحذف السريع.

### 2. حذف منتج من المتجر:
- اكتب أمر `/delete` أو `/list` في المحادثة.
- سيعرض لك البوت قائمة المنتجات الحالية مع زر **🗑️ حذف** لكل منتج.
- عند الضغط على زر الحذف، يطلب منك تأكيد الحذف ثم يقوم بإزالته فوراً من قاعدة البيانات والموقع.
- يمكنك أيضاً الحذف المباشر بكتابة:
  `/delete <SKU أو ID>` (مثال: `/delete 71635`).

### 3. استعادة المنتجات الافتراضية:
- في حال أردت إعادة المنتجات الأصلية الـ 5 في أي وقت، اكتب:
  `/reset`

## 🚀 واجهات الـ REST API

| الطريقة | المسار | الوظيفة |
| :--- | :--- | :--- |
| `GET` | `/api/products` | جلب جميع المنتجات الحالية (يدعم CORS للموقع) |
| `POST` | `/api/products` | إضافة منتج جديد برمجياً (JSON) |
| `DELETE` | `/api/products/:id` | حذف منتج بواسطة الـ ID أو الـ SKU |
| `GET` | `/api/images/:id` | جلب الصور المخزنة في السحابة |
| `POST` | `/api/reset` | إعادة تعيين المنتجات إلى الافتراضية |
| `POST` | `/telegram/webhook` | معالجة أحداث وتحديثات بوت التيليجرام |
| `GET` | `/telegram/set-webhook` | إعادة ربط الـ Webhook تلقائياً |
